🚀 Project Highlight: Diabetes Prediction with Kubeflow

Built an end-to-end machine learning pipeline using Kubeflow, working with a real-world healthcare dataset to predict whether a person is diabetic based on key health metrics.

🔹 Automated the entire ML lifecycle from model training to evaluation and deployment
🔹 Used **Kubeflow** Pipelines to create scalable, reproducible, and modular workflows 
🔹 Leveraged Kubernetes for efficient resource management and scalability
🔹Used **FastApi** to test the model with new datasets
